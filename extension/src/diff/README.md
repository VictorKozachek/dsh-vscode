# `extension/src/diff` — DiffService (#010)

Правки показываются диффом до применения, применяются одной транзакцией с
проверкой конфликта и откатываются (`DSH: Revert Last Edit`).

| Файл | Что делает |
|---|---|
| `diffService.ts` | ядро без `vscode`: нормализация правок, границы воркспейса, хеши, предпросмотр/применение/откат, строчный diff |
| `diffController.ts` | VS Code-обвязка: `vscode.diff` через виртуальный документ, `WorkspaceEdit` (undo редактора), команда отката |

## Правки

- `replaceFile` — полная замена содержимого;
- `replaceText` — точечная замена фрагмента (неоднозначность — ошибка, если не
  передан `all: true`);
- `replaceLines` — замена диапазона строк (1-based, включительно; `endLine =
  startLine - 1` — вставка).

```ts
const diff = new DiffService({ workspaceRoot });
const preview = await diff.preview([
  { path: 'src/app.ts', operations: [{ kind: 'replaceText', find: 'a = 1', replace: 'a = 2' }] }
]);
// preview.files[0].textEdits — минимальные замены строк для vscode.diff

const result = await diff.apply(preview.id);   // 'applied' | 'conflict' | 'failed'
await diff.revertLast();                        // 'reverted' | 'conflict' | 'empty'
```

## Гарантии

- **Предпросмотр не пишет файлы.** Он считает новые содержимые, хеши
  (`sha256`) и минимальные строчные правки.
- **Конфликт не затирает чужие изменения.** `apply` сначала сверяет хеши всех
  файлов; расхождение → `{ status: 'conflict', path }` без единой записи.
  `revertLast` так же сверяет применённое содержимое.
- **Транзакция.** При ошибке записи середины пачки уже записанные файлы
  возвращаются к исходному содержимому (`status: 'failed'`).
- **Границы.** Правка вне корня воркспейса (`../`, абсолютный путь снаружи,
  симлинк наружу) отклоняется `DiffServiceError` с кодом `outside-workspace`.
- Новые файлы создаются, а откат удаляет их (при наличии `removeFile` в порту).

## VS Code

`DiffController` (создаётся в #011, когда известен воркспейс):

1. `preview(edits)` — открывает `vscode.diff` «файл на диске ↔ виртуальный
   документ» (схема `dsh-diff`, содержимое по хешу), файлы не меняются;
2. `apply(previewId)` — проверяет хеши и применяет один `WorkspaceEdit`
   (`createFile` для новых файлов), поэтому отмена — обычный undo редактора;
3. `revertLastEdit()` — `DSH: Revert Last Edit` (команда объявлена в манифесте
   и зарегистрирована в активации; сервис подключается через
   `setDiffController`).
