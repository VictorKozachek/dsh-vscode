## Задача

Показать kanban-доску проекта внутри VS Code (read-only, без права двигать карточки).

- `extension/src/views/kanban*`: парсер `.kanban/tasks/*.md` (front matter +
  markdown-тело), группировка по колонкам `backlog/todo/in-progress/in-review/
  testing/ready/merged/blocked`.
- `webview/src/kanban/`: колонки, карточки (id, title, owner, branch, updated),
  клик — открыть файл карточки в редакторе; бейдж «в ветке» для worktree-копий.
- Обновление по watcher'у файлов с debounce; ручная кнопка обновить.
- Никаких записей в `.kanban/` из панели: движение карточек — вне скоупа.
- Тесты: парсер (битый front matter, кириллица), группировка, рендер.

## Критерии готовности

- [ ] Доска отражает реальные карточки проекта и обновляется при их изменении.
- [ ] Клик по карточке открывает `.kanban/tasks/<id>.md`.
- [ ] Панель ничего не пишет на диск (тест на read-only).
- [ ] Тесты зелёные.
