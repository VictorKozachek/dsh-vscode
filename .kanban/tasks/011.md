## Задача

Главный сценарий продукта: смена папки переключает контекст и сессии.

- Состояние воркспейса: `resolving → loading-context → ready → paused →
  teardown` (машина состояний в `extension/src/workspace/lifecycle.ts`).
- `onDidChangeWorkspaceFolders`: debounce, пауза текущей сессии, загрузка нового
  контекста (#006), восстановление последней сессии (#007), обновление статус-бара.
- Grace period (по умолчанию 10 мин): процесс DSH старого воркспейса остаётся
  живым, быстрый возврат — мгновенный; по истечении — shutdown и GC.
- Никакого протекания контекста: события старого воркспейса отбрасываются по id.
- Настройка `dsh.workspace.graceMinutes`.
- Тесты: переключение A→B→A, задержки, teardown по таймеру (fake timers),
  отсутствие событий из старого воркспейса.

## Критерии готовности

- [ ] Переключение папки в тестовом харнессе меняет активный воркспейс и сессию.
- [ ] Возврат в течение grace period не перезапускает процесс.
- [ ] После teardown процессы не висят (проверка супервизора).
- [ ] Тесты зелёные.

### Сделано (закоммичено в `task/011`, коммит `8ea5ddf`)

**`extension/src/workspace/lifecycle.ts`** — машина состояний без `vscode`:
- состояния `resolving → loading-context → ready → paused → teardown`;
- `activate(folder)`: создаёт рантайм, грузит контекст (#006), восстанавливает
  последнюю сессию (#007); при переключении A→B сессия A ставится на паузу и
  остаётся живой grace period (по умолчанию 10 минут, `dsh.workspace.graceMinutes`);
  возврат в A в окне grace — `resume()` без перезапуска процесса, по истечении —
  `dispose()` и GC (`teardown`);
- `handleWorkspaceFolders(folders)` — debounce смены папок, пустой список
  деактивирует; публичные операции сериализуются (A→B→A без гонок);
- `acceptsEvent(workspaceId)` — события старого воркспейса отбрасываются по id;
- `graceMsFromMinutes` — разбор настройки (мусор → 10 минут).

**`extension/src/workspace/lifecycleController.ts`** — VS Code-обвязка:
`onDidChangeWorkspaceFolders` → `resolveWorkspace` (#002) → рантайм
(`DshBridge` + `SessionManager` с реестром #003/#007 + `ContextLoader` #006);
статус-бар обновляется по состояниям; подключается в `activate()`.

**Манифест** — настройка `dsh.workspace.graceMinutes` (number, default 10,
minimum 0); ожидания `tests/manifest.test.mjs` дополнены.
