## Задача

Связать чат с выбранной сессией: сейчас панель живёт «одной сессией» и отвечает
эхом; нужно — история на сессию, переключение, стоп, статус.

- `extension/src/views/chat*`: чат слушает активную сессию из `SessionManager`;
  при переключении — заменяет историю (replay из транскрипта, если доступен,
  иначе с чистого листа с пометкой).
- `webview/src/chat/`: шапка показывает имя сессии, пресет, модель, статус;
  composer блокируется без активной сессии (CTA «Создать сессию»);
  «Стоп» шлёт `turn.cancel` именно активной сессии.
- Сохранение черновика composer на сессию; индикатор «Думает…» из статуса
  рантайма; ошибки рантайма — баннер с повтором.
- События `token`/`tool.call` маршрутизируются по `sessionId`: события чужой
  сессии не попадают в ленту (тест).
- Расход: токены/время хода в статусной строке панели (если рантайм отдаёт).

## Критерии готовности

- [ ] Две сессии — две независимые истории; переключение не смешивает сообщения.
- [ ] Стоп отменяет ход только активной сессии (тест).
- [ ] Composer без сессии заблокирован и ведёт в создание.
- [ ] События неактивной сессии отбрасываются (тест маршрутизации).
- [ ] Переключение сессии не теряет черновик (тест).
