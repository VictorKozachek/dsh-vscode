## Задача

Multi-root и удалённые сценарии: один VS Code — несколько корней и хостов.

- Multi-root: primary-воркспейс (первая папка, переопределение настройкой/командой
  `DSH: Choose Primary Workspace`), объединённые правила с приоритетом primary,
  конфликты — в инспектор (#013).
- Remote: `vscode.env.remoteName` (`ssh`, `wsl`, `containers`), проверка наличия
  `dsh` на remote-хосте, сравнение версии с требуемой, понятный экран-инструкция
  вместо падения.
- WSL: трансляция путей Windows ↔ Linux для реестра и worktree.
- Тесты: multi-root с двумя папками, remote-резолвер с фейковыми env, отсутствие
  бинаря, несовпадение версий.

## Критерии готовности

- [ ] Multi-root не ломает primary: он выбирается детерминированно и виден в UI.
- [ ] При отсутствии `dsh` пользователь видит инструкцию, расширение не падает.
- [ ] Тесты зелёные.
