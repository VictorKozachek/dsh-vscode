## Задача

Инспектор контекста и экран настроек — прозрачность того, что видит агент.

- `extension/src/views/context*`: дерево/панель: загруженные правила (файл →
  откуда), скилы, размер контекста, проигнорированные пути, конфликты правил и их
  разрешение.
- Кнопка «Reload Context» (команда `DSH: Reload Context`), время последней сборки.
- `webview/src/context/`: экран настроек `dsh.*` с валидацией и подсказками;
  изменение настроек применяется без рестарта там, где возможно.
- Тесты: рендер инспектора из фикстуры контекст-пака, валидация настроек.

## Сделано (`$(git rev-parse --short HEAD)`)

1. **Инспектор контекста.** Новый `extension/src/views/contextInspector.ts`
   строит модель из реального `ContextPack`: правила (путь, источник
   project/user/builtin, байты, усечение), скилы (путь/источник/описание),
   конфликты с объяснением «правило проекта победило пользовательский скил,
   project имеет приоритет §6», проигнорированные пути, manifestWarnings и
   статистика. `contextInspectorView.ts` — tree view `dsh.context` (группы
   Правила/Скилы/Конфликты/Проигнорированные), `registerContextInspector` в
   активации; данные — из активного lifecycle-рантайма (`contextPack`).
2. **Reload Context без рестарта.** `ContextLoader.reload()` сбрасывает кэш и
   собирает пак заново; `DshWorkspaceRuntime.reloadContext()` обновляет
   `contextPack`; команда `DSH: Reload Context` вызывает его, обновляет
   инспектор и показывает сводку. `Show Context Inspector` фокусирует view.
3. **Экран настроек `dsh.*`.** `webview/src/context/settingsModel.ts` —
   определения настроек, подсказки и валидация (enum, числа ≥0, список
   моделей строкой/массивом, значения по умолчанию); `SettingsScreen.tsx` —
   форма с ошибками/подсказками. Команда `DSH: Open Settings` открывает
   нативный экран и присылает `settingsOpen` в панель; `settingsApply`
   обновляет Workspace-настройки без рестарта.
4. **Тесты:** модель инспектора из фикстуры пака (источники/конфликт/пустой
   пак), валидация настроек (enum/числа/список/дефолты), activation —
   tree view `dsh.context` с реальным `AGENTS.md`, Reload Context обновляет пак
   и показывает сообщение, панель регистрирует view.
