## Задача

Диалог создания сессии «как в харнессе»: пресет, модель, sandbox, approval.

- `extension/src/views/newSession*.ts` + `webview/src/newSession/`: форма в
  webview (modal panel):
  - **Preset** — список пресетов рантайма (`standard` + роли `dispatcher`,
    `worker`, `reviewer`, `verifier`, если зарегистрированы); по умолчанию
    последний использованный; описание пресета рядом.
  - **Model** — список моделей профиля (из настроек/рантайма), поиск, дефолт из
    `dsh.defaultModel`.
  - **Sandbox** — `read-only` / `workspace-write` / `danger-full-access`
    (дефолт `dsh.sandboxMode`), предупреждение для `danger-full-access`.
  - **Approval** — `ask` / `auto` / `never` (дефолт `dsh.approvalPolicy`).
  - **Title** — необязательный, иначе генерируется из пресета и времени.
- Валидация: пустые/недопустимые значения блокируют «Создать»; ошибки рантайма
  показываются в форме.
- После создания: сессия появляется в списке (#022) и становится активной,
  чат (#024) переключается на неё.
- Запоминание последних выбранных значений в `workspaceState`/`globalState`.
- i18n ru/en, доступность с клавиатуры, фокус-ловушка.

## Критерии готовности

- [ ] Создание сессии с выбранными пресетом/моделью/sandbox/approval реально
      уходит в рантайм и возвращает id (тест на моке + ручная проверка).
- [ ] Список пресетов подтягивается из рантайма, `standard` есть всегда.
- [ ] Значения по умолчанию берутся из настроек, последние — запоминаются.
- [ ] `danger-full-access` требует явного подтверждения.
- [ ] Ошибка создания не ломает панель и показывается в форме.
