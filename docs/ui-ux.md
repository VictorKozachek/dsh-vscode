# DSH for VS Code — UI/UX дизайн

Статус: черновик 1.0 (18.11.2026). Источник: SPECIFICATION.md §6, §16, §17.

## 1. Раскладка

```
┌──────────┬──────────────┬───────────────────┬──────────────────┐
│ Activity │ Explorer /   │ Редактор кода     │ Secondary        │
│ Bar      │ файлы        │ (код, диффы)      │ Sidebar:         │
│          │              │                   │  Sessions        │
│  DSH ──► │              │  ┌─────────────┐  │  Context         │
│          │              │  │ Chat (Beside)│  │  Kanban          │
└──────────┴──────────────┴──┴─────────────┴──┴──────────────────┘
```

- Слева — стандартный VS Code: activity bar, explorer, SCM, debug. Не трогаем.
- Центр — редактор кода; чат открывается **сплитом справа** от него (`ViewColumn.Beside`), код остаётся видимым.
- Справа — DSH Sessions/Context/Kanban в Secondary Sidebar (перетаскивается пользователем один раз, позиция запоминается).
- Клик по DSH в activity bar: фокус на контейнере + открыт чат; повторный клик не плодит вкладки.

## 2. Chat panel (большое окно)

| Зона | Содержимое |
|---|---|
| Header | имя сессии, бейдж пресета, модель, чип sandbox, кнопка Stop |
| Feed | сообщения user/assistant; tool-call блоки (свёрнуты, статус, длительность, результат); diff-ссылки; streaming-каретка; автоскролл у нижней границы |
| Composer | textarea (Enter — send, Shift+Enter — newline), кнопка **emoji**: поповер с поиском и категориями, вставка в позицию курсора; недавние; кнопка Send; подсказка; вложения/выделение |
| Footer | статус (idle/streaming/cancelled/error), токены, длительность хода |

Состояния: пустая («Nothing here yet» + подсказка), нет сессии (CTA «Создать сессию»), streaming, cancelled, error (баннер с повтором), offline (read-only).

## 2.1. Таб-бар большой панели

Большая панель (WebviewPanel) содержит табы:

| Таб | Содержимое | Когда виден |
|---|---|---|
| **Chat** | разговор текущей сессии | всегда |
| **Board** | kanban-доска проекта карточками | если есть `.kanban/tasks` и kanban не выключен |

- Активный таб запоминается по воркспейсу; переключение без перезагрузки webview.
- На табе Board — бейдж статуса плагина (`dsh-kanban активен` / `не установлен`).
- Кнопка «Показать доску» — в шапке чата; команда `DSH: Показать доску`.
- `Cmd/Ctrl+Alt+B` — переключить на Board; повторно — назад в Chat.

## 3. Sessions panel

- Заголовок: `📁 <воркспейс>` + счётчик сессий.
- Строка: название (title из метаданных), относительное время (`now/2min/4d/2mo`), статус-точка, hover-действия (открыть, переименовать, стоп).
- Активная сессия выделена фоном + точкой.
- Поиск по названию; сортировка по времени.
- Пустое состояние: «Сессий нет — создайте первую» + кнопка «+».
- Ошибка рантайма: «Менеджер сессий не подключён» + ссылка «Настройки DSH».

## 4. Kanban board

- Колонки: `backlog, todo, in-progress, in-review, testing, ready, merged` (+ `blocked`), горизонтальный скролл, sticky-заголовки со счётчиками.
- Карточка: `#012`, заголовок (2 строки), бейджи owner/branch/«в ветке», время, расход токенов (tooltip).
- Действия: drag `backlog ↔ todo` (асайн), контекстное меню: «В работу», «В backlog», «Влить», «Открыть карточку/диф».
- Пусто: «Нет `.kanban/tasks` — создать доску?» + команда.
- Статус плагина: баннер «плагин не установлен» → «Установить» / «Работать со встроенной доской».

## 5. Context panel

Дерево: правила (файл → откуда), скилы, конфликты, проигнорированные пути, размер пака; кнопка Reload; при ошибке — понятное сообщение.

## 6. Status bar

`DSH · <воркспейс> · <synced with app | standalone | offline> · <model> · <sandbox>`; клик — диагностика.

## 8. Дизайн-система

- Только токены VS Code: `--vscode-*` (foreground, descriptionForeground, buttonBackground, inputBackground, focusBorder, editorWidget.background, contrastBorder…).
- Сетка 4/8 px, базовый шрифт 13px (UI) / 12px (meta), радиусы 4–6px.
- Иконки — Codicons; статус-точки: idle (зелёная), streaming (анимированная), error (красная), locked (жёлтая).
- Контраст ≥ 4.5:1 в обеих темах; фокус-кольцо всегда видно.
- Доступность: полная клавиатурная навигация, ARIA-роли, фокус-ловушка в диалогах, `prefers-reduced-motion`.

## 8.1. Emoji и Unicode

**Выбор смайла в composer** (запрос пользователя 18.11): кнопка 😊 рядом с Send
открывает поповер:
- поиск по названию (`smile`, `rocket`), категории (часто используемые, реакции,
  статусы, объекты, символы), недавние (запоминаются в `workspaceState`);
- вставка в позицию курсора, фокус возвращается в textarea, Enter не отправляет;
- поддержка системного пикера (`Cmd+Ctrl+Space` на macOS) в textarea тоже
  должна работать;
- поповер закрывается по Esc и клику вне; навигация стрелками.

**Рендер**: смайлы — обычный Unicode-текст, не вырезать (проверить
`escapeHtml`/markdown на `😀 🚀 ✅ ❌` и составные эмодзи 👨‍👩‍👧‍👦, флаги, skin tone).
- Шрифтовой стек с fallback: `var(--vscode-font-family), system-ui, -apple-system,
  "Apple Color Emoji", "Segoe UI Emoji", "Noto Color Emoji", sans-serif`.
- Моноширинный код — с эмодзи-fallback тем же списком.
- Тест: сообщение с эмодзи в начале/середине/конце, в коде и в tool-call аргументах;
  surrogate pairs не ломаются; ширина/выравнивание не съезжают.

## 9. Взаимодействия (сквозные)

1. Клик по сессии → открыть чат Beside + подгрузить историю.
2. «+» в сессиях → диалог New Session → создание → чат открыт на новой сессии.
3. Смена папки → sessions/context обновляются, чат переключается на сессию нового воркспейса.
4. Перетаскивание карточки `backlog→todo` → асайн через скрипт → наряд роли.
5. Approvals приходят инлайн в ленту чата, не модалкой.
6. Ошибки рантайма — баннеры с действиями, без модальных окон.
