## Задача

Потоковый чат: ответы агента, блоки вызова инструментов, отмена.

- `webview/src/chat/`: потоковые токены в ленте, блок `tool.call` (имя, аргументы,
  статус, длительность, результат свёрнутый), markdown с безопасным рендером
  (без raw HTML), code blocks с копированием, автоскролл только если пользователь
  у нижней границы.
- `extension/src/views/chat*`: подписка на события `DshBridge` → `postMessage`,
  батчинг токенов (не чаще 30 fps), отмена через `turn.cancel`.
- Состояния: idle, streaming, cancelled, error — с понятными индикаторами.
- Тесты: reducer ленты (событие → состояние), отмена, батчинг; рендер-тесты на
  безопасность HTML.

## Критерии готовности

- [ ] Длинный ответ стримится без дёрганья скролла и без утечек listener'ов.
- [ ] Отмена останавливает поток и помечает сообщение «остановлено».
- [ ] Сообщения с HTML/скриптами не исполняются в webview (тест XSS).
- [ ] Тесты `node --test` + webview-тесты зелёные.
