## Задача

Показать в VS Code список сессий DSH — как в Web GUI: текущий воркспейс, все
сессии, активная сессия, создание новой.

- `contributes.views`: view `dsh.sessions` в контейнере DSH (рядом с чатом),
  иконка, заголовок, кнопки `+` (создать) и `⟳` (обновить).
- `extension/src/views/sessionsView.ts`: `TreeDataProvider`/`WebviewView`:
  группировка по дате/статусу, бейджи `active`/`idle`/`error`, подпись с моделью
  и пресетом, tooltip.
- Клик по сессии — сделать её активной (событие наружу, его слушает чат #024).
- Контекстное меню: `Resume`, `Stop`, `Rename`, `Delete` (осознанно, с
  подтверждением), `Open Transcript` (если транскрипт доступен).
- Состояния: загрузка, пусто («Сессий нет — создайте первую»), ошибка рантайма
  (с действием «Повторить» и ссылкой на настройку `dsh.executablePath`).
- Обновление по событиям рантайма (#021), fallback — polling раз в 5 с при
  открытой панели; refresh вручную.
- Никаких прямых вызовов HTTP из view: данные — через `SessionManager` (#007),
  который ходит в `DshBridge`.

## Критерии готовности

- [ ] Список показывает реальные сессии воркспейса (интеграционный тест на мок-мосту).
- [ ] Клик по сессии переключает активную; активная визуально выделена.
- [ ] Создание из `+` открывает диалог #023 (или заглушку до её слияния).
- [ ] Пустое состояние и состояние ошибки отрисованы и покрыты тестом.
- [ ] Панель не падает при остановленном рантайме.

### Сделано (закоммичено в `task/022`, коммит `1295bd2`)

**Манифест:** view `dsh.sessions` (type `tree`) в контейнере DSH рядом с
`dsh.chat`; кнопки `+`/`⟳` в `view/title`; команды `dsh.sessions.create`,
`refresh`, `select`, `resume`, `stop`, `rename`, `delete`, `openTranscript`;
`view/item/context` меню для `dshSession`/`dshSession.active`; `viewsWelcome`
для пустого состояния («Сессий нет — создайте первую» + кнопка).

**`extension/src/views/sessionsModel.ts`** (чистая модель):
- группы «Сегодня/Вчера/Ранее» по локальной дате, активная первой, затем по
  `updatedAt`; бейджи `active`/`idle`, подписи (`title` или короткий id),
  tooltip с id/воркспейсом/временем;
- состояния `loading`/`empty`/`error`/`ready`; `error` включает «Повторить» и
  подсказку `dsh.executablePath`; `offline` рантайма не роняет панель;
- `SessionRefreshLoop` — fallback-опрос раз в 5 с только пока панель видима,
  события рантайма сбрасывают таймер (не размножают).

**`extension/src/views/sessionsController.ts`** — работа только через
`SessionManager` (#007): `list`, `resume` по клику, `create`, `pause`,
необязательные `rename`/`remove`/`openTranscript` (без поддержки рантайма
команда возвращает `false`, view сообщает об этом); подписки на
`sessionChanged`/`statusChanged`; сериализованные refresh.

**`extension/src/views/sessionsView.ts`** — `TreeDataProvider`, иконки
`pass-filled`/`circle-outline`/`error`, placeholder-строки загрузки и ошибки,
контекстные ключи `dsh.sessions.empty/error`, команды и меню, `Rename` через
`showInputBox`, `Delete` — модальное подтверждение. Источник ленивый: пока
`SessionManager` не подключён (#011), панель показывает ошибку с retry, а не
падает.
