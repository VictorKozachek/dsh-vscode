## Задача

`DiffService`: показать правку до применения, применить с undo, откатить.

- `extension/src/diff/`: нормализация предложенных правок (полная замена файла и
  точечные патчи) в `WorkspaceEdit`; предпросмотр через `vscode.diff` или
  виртуальный документ.
- Применение: пачка правок одной транзакцией (по возможности), проверка, что файл
  не изменился с момента предпросмотра (хеш) — иначе конфликт и отказ.
- Откат: undo-стек редактора + команда `DSH: Revert Last Edit`.
- Границы: запись только в пределах корня воркспейса; отказ — понятная ошибка.
- Тесты: предпросмотр → применение → undo на временном воркспейсе; конфликт
  версий; правка вне корня отклоняется.

## Критерии готовности

- [ ] Правка показывается диффом до применения; отмена не меняет файл.
- [ ] После применения `undo` возвращает исходное содержимое (тест).
- [ ] Конфликт (файл изменился) не затирает чужие изменения.
- [ ] Тесты зелёные.

## Заметки исполнителя

### Сделано (закоммичено в `task/010`, коммит `6df1285`)

**`extension/src/diff/diffService.ts`** — ядро без `vscode`, тесты на временном
воркспейсе:
- нормализация правок: `replaceFile` (полная замена), `replaceText` (точечная,
  с ошибкой на неоднозначности и `all: true`), `replaceLines` (диапазон строк);
- предпросмотр ничего не пишет: считает новые содержимые, `sha256`-хеши
  исходника/результата и минимальные строчные правки (`computeLineEdits`) для
  `vscode.TextEdit`;
- применение транзакцией: сначала сверяются хеши **всех** файлов (конфликт →
  `{ status: 'conflict' }` без единой записи), затем запись; ошибка середины
  пачки откатывает уже записанные файлы к исходному содержимому;
- откат (`revertLast`) сверяет применённое содержимое: чужие правки после
  применения → конфликт, файл не трогаем; созданные файлы удаляются;
- границы: `../`, абсолютный путь снаружи и симлинк наружу -> `DiffServiceError`
  с кодом `outside-workspace` (realpath, если доступен).

**`extension/src/diff/diffController.ts`** — VS Code-обвязка: `vscode.diff` через
виртуальный документ (`dsh-diff`), применение одним `WorkspaceEdit` (undo
редактора, `createFile` для новых файлов), проверка хешей перед применением,
`revertLastEdit()`.

**Команда:** `DSH: Revert Last Edit` (`dsh.revertLastEdit`) объявлена в
манифесте и зарегистрирована в `activate()`; контроллер подключается через
`setDiffController()` (#011). Пока контроллера нет — понятное сообщение
«откатывать нечего».

### Тесты — `tests/diff-service.test.mjs` (11)

предпросмотр не меняет файл → применение → откат возвращает исходное;

симлинк наружу); откат транзакции при ошибке записи; откат после чужих правок —
конфликт; создание/удаление нового файла; `computeLineEdits`; хеши.
