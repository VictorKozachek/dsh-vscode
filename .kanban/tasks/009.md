## Задача

Подтверждения и sandbox-политики: инлайн-диалоги вместо модальных окон.

- `webview/src/approvals/`: инлайн-карточка `approval.request` с кнопками
  «Разрешить», «Разрешить для этой сессии», «Отклонить», «Показать diff»;
  фокус-ловушка и клавиатура.
- `extension/src/approvals/`: политика `ask`/`auto`/`never` (per tool type),
  маппинг sandbox-режимов `read-only`/`workspace-write`/`danger-full-access`,
  обязательное подтверждение для записи вне воркспейса и сетевых вызовов.
- Аудит: `.dsh/audit.log` (JSONL, ротация по размеру), без секретов.
- Fallback: если панель скрыта — `vscode.window.showInformationMessage` с теми же
  действиями (не блокирующий модал).
- Тесты: разрешение политик, отклонение останавливает инструмент, аудит-запись.

## Критерии готовности

- [ ] «Отклонить» гарантированно останавливает инструмент (тест).
- [ ] `ask` для записи вне воркспейса даже при `auto` (тест).
- [ ] Аудит пишется, ротация работает, секретов нет.
- [ ] Тесты зелёные.
