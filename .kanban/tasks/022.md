## Задача

Показать в VS Code список сессий DSH — как в Web GUI: текущий воркспейс, все
сессии, активная сессия, создание новой.

- `contributes.views`: view `dsh.sessions` в контейнере DSH (рядом с чатом),
  иконка, заголовок, кнопки `+` (создать) и `⟳` (обновить).
- `extension/src/views/sessionsView.ts`: `TreeDataProvider`/`WebviewView`:
  группировка по дате/статусу, бейджи `active`/`idle`/`error`, подпись с моделью
  и пресетом, tooltip.
- Клик по сессии — сделать её активной (событие наружу, его слушает чат #024).
- Контекстное меню: `Resume`, `Stop`, `Rename`, `Delete` (осознанно, с
  подтверждением), `Open Transcript` (если транскрипт доступен).
- Состояния: загрузка, пусто («Сессий нет — создайте первую»), ошибка рантайма
  (с действием «Повторить» и ссылкой на настройку `dsh.executablePath`).
- Обновление по событиям рантайма (#021), fallback — polling раз в 5 с при
  открытой панели; refresh вручную.
- Никаких прямых вызовов HTTP из view: данные — через `SessionManager` (#007),
  который ходит в `DshBridge`.

## Критерии готовности

- [ ] Список показывает реальные сессии воркспейса (интеграционный тест на мок-мосту).
- [ ] Клик по сессии переключает активную; активная визуально выделена.
- [ ] Создание из `+` открывает диалог #023 (или заглушку до её слияния).
- [ ] Пустое состояние и состояние ошибки отрисованы и покрыты тестом.
- [ ] Панель не падает при остановленном рантайме.
