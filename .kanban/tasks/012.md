## Задача

Multi-root и удалённые сценарии: один VS Code — несколько корней и хостов.

- Multi-root: primary-воркспейс (первая папка, переопределение настройкой/командой
  `DSH: Choose Primary Workspace`), объединённые правила с приоритетом primary,
  конфликты — в инспектор (#013).
- Remote: `vscode.env.remoteName` (`ssh`, `wsl`, `containers`), проверка наличия
  `dsh` на remote-хосте, сравнение версии с требуемой, понятный экран-инструкция
  вместо падения.
- WSL: трансляция путей Windows ↔ Linux для реестра и worktree.
- Тесты: multi-root с двумя папками, remote-резолвер с фейковыми env, отсутствие
  бинаря, несовпадение версий.

## Критерии готовности

- [ ] Multi-root не ломает primary: он выбирается детерминированно и виден в UI.
- [ ] При отсутствии `dsh` пользователь видит инструкцию, расширение не падает.
- [ ] Тесты зелёные.

## Сделано (`$(git rev-parse --short HEAD)`)

1. **Multi-root primary.** `resolveWorkspace` упорядочивает папки по `index`
   (детерминированно), `primaryFolder` (имя или канонический путь)
   переопределяет primary; неизвестное значение игнорируется. Настройка
   `dsh.primaryWorkspace` + команда `DSH: Choose Primary Workspace`
   (quick pick папок, сохраняет в Workspace-настройку). Статус-бар/панель
   показывают имя primary, а не просто первую папку. Тесты: override по
   имени/пути, неизвестный override → минимальный index, activation-тест
   primary в статус-баре и смена командой.
2. **Remote.** Новый `extension/src/workspace/remote.ts`: `remoteKind`
   (`local/ssh/wsl/containers/other`), `compareVersions`,
   `checkRemoteRuntime` — отсутствие бинаря и старая версия возвращают
   понятную инструкцию (`REMOTE_INSTRUCTIONS`, обновление npm), а не
   исключение. В activation при `remoteName` и состоянии `running`
   показывается warning с инструкцией вместо падения. Тесты: kinds,
   semver-сравнение, missing/version-mismatch/ok.
3. **WSL-пути.** `windowsPathToWsl` (`C:\repo` → `/mnt/c/repo`),
   `wslPathToWindows`, `translateWorkspacePath` (для registry/worktree);
   путь реестра `dsh.workspace.registryPath` транслируется для WSL/Windows.
   Тесты трансляции.
4. **Инспектор конфликтов правил** — #013 (граница), multi-root правила
   объединяются там.
