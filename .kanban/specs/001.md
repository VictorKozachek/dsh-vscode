# Спека 001: DSH for VS Code — MVP расширения по SPECIFICATION.md

Статус: черновик, нарезана на карточки #001–#017.

## Зачем

Перенести полный функционал DeepSeek Harness в VS Code так, чтобы воркспейс
определялся по открытой папке, а при её смене поднимались контексты, скилы и
правила проекта. Полная спецификация — `SPECIFICATION.md`; план исполнения —
`PLAN.md`. Эта спека — основание нарезки: одна карточка = один срез работы.

## Результат MVP (критерии приёмки, §12 спецификации)

1. Открытие папки поднимает воркспейс без ручных действий, статус-бар показывает верное имя.
2. Смена папки переключает контекст: агент не видит файлы предыдущего проекта.
3. Возврат к папке восстанавливает последнюю сессию и историю.
4. Правка файла агентом показывается диффом и откатывается через undo.
5. Approval-запросы работают инлайн; «отклонить» останавливает инструмент.
6. Рестарт IDE не теряет сессию.
7. Multi-root не ломает определение primary-воркспейса.
8. Нет секретов в реестре, логах и контекст-паке.

## Требования по этапам

### M0 — каркас и определение воркспейса

- [ ] Монорепо: `extension/` (TypeScript, extension host), `webview/`,
      `protocol/`, общая сборка и линт; расширение активируется и показывает
      статус-бар.
- [ ] `WorkspaceResolver`: канонический корень (realpath, регистр), `git remote`,
      remote-хост, primary при multi-root, идентификатор `sha256[:16]`.
- [ ] `WorkspaceRegistry`: `~/.dsh/workspaces/<id>.json`, атомарная запись,
      миграции версии, GC; секреты не пишутся.
- [ ] `DshBridge`: JSON-RPC 2.0 поверх stdio, supervisor (spawn, backoff,
      healthcheck, graceful shutdown), схема в `protocol/`.

### M1 — агент и контекст

- [ ] Панель DSH: activity bar container + WebView (лента, composer, шапка,
      статус), тёмная/светлая темы, доступность.
- [ ] `ContextLoader`: `AGENTS.md` (корень и вложенные), `.dsh/workspace.json`,
      скилы, индекс файлов с игнорами, кэш по mtime и hot reload.
- [ ] `SessionManager`: create/resume/list/pause, восстановление после рестарта IDE.
- [ ] Потоковый чат с tool-call-блоками, отмена хода.
- [ ] Approvals: инлайн-диалоги, политики `ask`/`auto`/`never`, маппинг
      sandbox-режимов, аудит-лог.
- [ ] `DiffService`: предпросмотр правок, `WorkspaceEdit` с undo, откат.

### M2 — переключение воркспейсов

- [ ] Смена папки: `onDidChangeWorkspaceFolders`, pause/resume, grace period,
      GC процессов, восстановление сессии.
- [ ] Multi-root, remote/WSL/SSH/Codespaces, проверка наличия `dsh`-бинаря.
- [ ] Инспектор контекста и UI настроек.

### M3 — экосистема

- [ ] Kanban-панель расширения (`.kanban/tasks`).
- [ ] Терминал-мост и диагностика как контекст.
- [ ] Визуализация субагентов.
- [ ] VSIX-сборка, CI (GitHub Actions), пользовательская документация.

## Вне скоупа MVP

- Публикация в VS Code Marketplace (VSIX из репозитория).
- Собственный inference-стек, прокси моделей, биллинг.
- Мобильные клиенты и браузерное расширение.
- Несколько исполнителей на один воркспейс одновременно (следующая итерация).
