## Задача

Терминал и диагностика как инструменты агента.

- `extension/src/terminal/`: создание терминала, отправка команд по запросу
  инструмента, захват вывода через shell integration; подтверждение для команд,
  меняющих систему; таймауты и отмена.
- `extension/src/diagnostics/`: сбор `vscode.languages.getDiagnostics` по
  активным файлам (лимит по количеству/размеру), новый метод моста
  `diagnostics.report` — передача агенту как контекста.
- Безопасность: команды никогда не выполняются без approval по политике (#009).
- Тесты: буфер вывода, таймаут, лимиты диагностики, отсутствие shell integration.

## Критерии готовности

- [ ] Агент получает вывод команды и код возврата.
- [ ] Диагностика передаётся с лимитами и не тормозит UI.
- [ ] Команда без approval не выполняется (тест).
- [ ] Тесты зелёные.
