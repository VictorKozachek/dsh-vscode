## Задача

Диалог создания сессии «как в харнессе»: пресет, модель, sandbox, approval.

- `extension/src/views/newSession*.ts` + `webview/src/newSession/`: форма в
  webview (modal panel):
  - **Preset** — список пресетов рантайма (`standard` + роли `dispatcher`,
    `worker`, `reviewer`, `verifier`, если зарегистрированы); по умолчанию
    последний использованный; описание пресета рядом.
  - **Model** — список моделей профиля (из настроек/рантайма), поиск, дефолт из
    `dsh.defaultModel`.
  - **Sandbox** — `read-only` / `workspace-write` / `danger-full-access`
    (дефолт `dsh.sandboxMode`), предупреждение для `danger-full-access`.
  - **Approval** — `ask` / `auto` / `never` (дефолт `dsh.approvalPolicy`).
  - **Title** — необязательный, иначе генерируется из пресета и времени.
- Валидация: пустые/недопустимые значения блокируют «Создать»; ошибки рантайма
  показываются в форме.
- После создания: сессия появляется в списке (#022) и становится активной,
  чат (#024) переключается на неё.
- Запоминание последних выбранных значений в `workspaceState`/`globalState`.
- i18n ru/en, доступность с клавиатуры, фокус-ловушка.

## Критерии готовности

- [ ] Создание сессии с выбранными пресетом/моделью/sandbox/approval реально
      уходит в рантайм и возвращает id (тест на моке + ручная проверка).
- [ ] Список пресетов подтягивается из рантайма, `standard` есть всегда.
- [ ] Значения по умолчанию берутся из настроек, последние — запоминаются.
- [ ] `danger-full-access` требует явного подтверждения.
- [ ] Ошибка создания не ломает панель и показывается в форме.

**`extension/src/views/newSessionModel.ts`** — модель формы без `vscode`:
- значения по умолчанию: `dsh.defaultModel` / `dsh.sandboxMode` /
  `dsh.approvalPolicy`, затем последние запомненные; `standard` всегда есть и

- валидация: пустые/неизвестные пресет и модель, неизвестные sandbox/approval,
  длина заголовка; `danger-full-access` требует явного `confirmDanger`;
- заголовок: введённый или сгенерированный из пресета и времени;
  `buildCreateOptions`, `rememberedFromValues`, ключ `dsh.newSession.last`.

**`extension/src/views/newSessionController.ts`** — диалог поверх портов
(`getPresets`, `getModels`, `create`, `getSettings`, `getRemembered`,
`remember`, `view`): `open()` собирает форму; `submit()` валидирует, при ошибках
возвращает их в форму без создания; при ошибке рантайма форма остаётся
открытой с сообщением (`errors.form`); при успехе — `remember` и закрытие;
`cancel()`; операции сериализованы.

**`webview/src/newSession/`** — `newSessionModel.ts` (зеркальная валидация,
поиск моделей, `Esc`/`Ctrl+Enter`, фокус по кругу) и `NewSessionModal.tsx`
(modal: preset + описание, model с поиском, sandbox-радио с предупреждением и
чекбоксом подтверждения, approval, заголовок; фокус-ловушка Tab/Shift+Tab;
ошибки полей и общая; i18n ru/en).

**Контракт сообщений** (`chatHtml.ts` + `webview/src/messages.ts`, паритет
тестом): WebView→extension `newSessionSubmit`/`newSessionCancel`,
extension→WebView `newSessionOpen`/`newSessionUpdate`/`newSessionClose`;
диспетчер маршрутизирует их в порт `newSession`, провайдер панели принимает
порт. В `activate()`: `dsh.newSession` при подключённом менеджере открывает
форму (фокусируя панель чата), иначе — прежнее понятное сообщение; `create`
вызывает `SessionManager.create({title, model})` (в `session.create` уходит
`model`), последние значения — в `globalState` под `dsh.newSession.last`.
